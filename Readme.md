
# Vertical Carousel

A visually appealing and interactive vertical carousel built using HTML, CSS, and JavaScript. This project showcases a touch-friendly carousel interface that provides a smooth user experience and can be implemented in a variety of web applications.






## Features

1. Interactive Carousel: Swipe or use the mouse wheel to navigate between carousel items.

2. Responsive Design: The carousel is fully responsive and looks great on all screen sizes.

3. Smooth Transitions: Transitions between carousel items are smooth and fluid.

4. Touch-Swipe Support: Swipe functionality is supported for mobile users.

3. Customizable: Easily extendable and customizable to fit different design needs.

## Folder Structure

The project folder structure looks like this:


- **index.html**: This is the main file that contains the HTML structure for the vertical carousel.
- **style.css**: Contains all the styling for the carousel and the overall layout.
- **main.js**: The JavaScript that handles the carousel logic, including swipe and mouse wheel interactions.
- **README.md**: Provides an overview of the project, installation instructions, and other documentation.




## Technology Used

1. HTML5: Structuring the page content.
2. CSS3: Styling and creating smooth transitions.
3. JavaScript: Handling swipe events, touch interactions, and wheel scrolling.
## How It works

The vertical carousel is a simple yet effective UI component that allows users to navigate through different items by swiping vertically or using the mouse wheel. The carousel uses the following techniques:
```
1. HTML Structure: The carousel is built using flexbox for centering and organizing the content boxes.

2. CSS Styling: A gradient background is applied, and the carousel items have a transparent backdrop with blur effects to create a visually attractive look.

3. JavaScript: The carousel rotation logic is handled using event listeners for touch, wheel, and mouse events. The positions of the carousel items are updated dynamically based on user interaction.
```
